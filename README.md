# KarDoors — сайт-каталог с заказами в Telegram

## Как это работает
Клиент выбирает двери → оставляет имя и телефон → сервер отправляет заявку вам в Telegram от имени вашего бота.
Каждая заявка также дублируется в файл `orders.jsonl` (резерв).

> Telegram не позволяет отправлять сообщения «на номер телефона» напрямую — только в чат с конкретным пользователем.
> Поэтому заявки приходят в ваш Telegram-аккаунт, привязанный к номеру +998 91 389 79 87.

## Настройка (10 минут)
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен** (`123456:AA...`).
2. Откройте своего нового бота и нажмите **Start** (без этого бот не сможет вам писать).
3. Узнайте свой **chat id**: напишите боту **@userinfobot** — он пришлёт число `Id`.
   (Для группы: добавьте бота в группу, id группы начинается с `-100…`.)
4. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN` и `CHAT_ID`.
5. Запуск: `node server.js` (нужен Node.js 18+, устанавливать пакеты не нужно) → http://localhost:3000

## Публикация в интернете
Нужен хостинг, который запускает Node.js (Render, Railway, Timeweb, любой VPS).
Команда запуска: `node server.js`, переменные `BOT_TOKEN` и `CHAT_ID` задайте в настройках хостинга.
Обычный статичный хостинг (GitHub Pages и т. п.) не подойдёт — токен бота нельзя хранить в коде страницы.

## Что редактировать
- `public/products.js` — модели, описания, **цены** (`price: 1200000` вместо `null`).
- `public/index.html` — тексты, контакты.
- `public/img/` — фото дверей.
